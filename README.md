## 关于 Darlink

Darlink 是面向北京大学和香港高校的一个社交平台。我们为每个人生成一个 AI Twin，让它先替你表达、回应和筛选。别人可以先和你的 AI 分身聊聊，看看你们是否同频；而你也可以在真正合适的人出现时，再自然地进入关系。找学习搭子、恋爱对象、朋友，或者只是一个懂你的人，Darlink 都让第一步变得更轻，也更接近真实的合拍。
